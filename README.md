## 🚀 Featured Projects

### 🔍 RAG Document Chatbot
> Retrieval-Augmented Generation system that answers questions over custom document corpora.
- Azure AI Search + OpenAI embeddings
- Chunking strategies, hybrid search, prompt engineering
- `Python` `LangChain` `Azure` `pgvector`

### 🤖 Autonomous GitHub Analyzer Agent
> LangGraph-powered agent that clones a repo, analyzes its structure and code quality, and generates a full technical report.
- Multi-step reasoning with state machines
- Tool use: file system, static analysis, LLM summarization
- `Python` `LangGraph` `LangSmith` `OpenAI`

### 🧩 AI-Native End-to-End System
> Production-grade system that receives a support ticket, retrieves context via RAG, routes decisions through a LangGraph agent, executes actions via MCP tools, and logs everything with full observability.
- Full tracing and debugging with LangSmith
- MCP integration for external tool access
- ROI-focused design, presentable to business stakeholders
- `Python` `LangGraph` `LangSmith` `MCP` `Azure` `Docker`
